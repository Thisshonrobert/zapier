# Phase 16C implementation plan

Execute inline with executing-plans and TDD. Preserve the current checkout and unrelated edits; no Git integration actions.

**Goal:** Establish role and durable routing foundation: independent engineering capability, application-owned case workflow with append-only human events, atomic decision handoffs, concurrency/idempotency protection, and local role provisioning.
**Spec:** `docs/AI/support-workspaces-and-dlq-lab-plan.md`, Section 3, Section 4 and Phase 16C.
**Architecture:** Additive Prisma schema (`isEngineer` on User, `TriageCaseWorkflow`, `TriageCaseWorkflowEvent`). Atomic transactions link operator decisions to durable case workflow transitions. An independent `EngineeringService` enforces that designated engineers see and act only on routed cases with complete audit logging and immediate revocation.
**Stack:** Existing Bun, TypeScript, Express, PostgreSQL/Prisma. No new external dependencies.
