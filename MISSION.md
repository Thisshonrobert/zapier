# Mission: Production-style AI systems

## Why
Build an Autonomous DLQ Triage Agent inside this repository while learning production AI-system design in the TypeScript/Bun stack already used by the project.

## Success looks like
- Build and explain a bounded LangGraph investigation workflow.
- Integrate LangGraph.js safely with the existing TypeScript and Kafka system.
- Evaluate diagnoses and gate every side effect with deterministic application code.

## Constraints
- Work in small, tested phases and teach the production decisions before coding.
- Keep the existing TypeScript backend, worker, Kafka infrastructure, and frontend.
- Keep language/tooling overhead low so lessons can focus on agents, evidence, safety, and evaluation.

## Out of scope
- Rebuilding the workflow platform or granting the LLM direct replay/database authority.
- Adding multi-agent, MCP, vector database, or production replay before evidence justifies it.
