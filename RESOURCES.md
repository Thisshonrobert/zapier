# Production AI Service Resources

## Knowledge

- [LangGraph.js Graph API](https://docs.langchain.com/oss/javascript/langgraph/graph-api)
  Primary framework documentation. Use for state, nodes, edges, reducers, and execution limits.
- [Express 5 API](https://expressjs.com/en/5x/api.html)
  Primary Express reference. Use for the local HTTP boundary and controlled server shutdown.
- [Zod documentation](https://zod.dev/)
  Primary validation guidance. Use at HTTP, tool, and model-output trust boundaries.
- [Resend idempotency keys](https://resend.com/docs/dashboard/emails/idempotency-keys)
  Provider documentation. Use when evaluating whether an email replay can be safe.
